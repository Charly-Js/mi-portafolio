# Charly-js Portfolio

Este es el portafolio personal de Carlos Eduardo Pinzón González, un desarrollador de software especializado en AI y desarrollo full-stack. El diseño está inspirado en el universo de Halo, combinando elementos sci-fi con un aspecto profesional.

## Características

- Diseño responsivo inspirado en Halo
- Modo oscuro y claro
- Secciones para proyectos, habilidades, sobre mí y contacto
- Animaciones y efectos visuales interactivos
- Integración de iconos de Lucide React
- Uso de Tailwind CSS para estilos
- Componentes de UI personalizados con shadcn/ui

## Tecnologías utilizadas

- Next.js 13 (App Router)
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React
- shadcn/ui
